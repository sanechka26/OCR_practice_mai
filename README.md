## 📖 Описание

Данный проект представляет собой систему оптического распознавания текста (OCR) на основе нейронной сети YOLO. Проект включает:

- ✅ Распознавание текста на изображениях
- ✅ Сохранение результатов в JSON формат
- ✅ Интеграцию с GigaChat API для валидации результатов
- ✅ Подготовку данных для дальнейшего анализа

**Область применения:** обработка документов, распознавание вывесок, оцифровка рукописного текста.

---

## ✨ Возможности

-  Высокая точность распознавания благодаря YOLOv8
- 📤 Экспорт результатов в структурированный JSON
- 🔗 API интеграция для постобработки текста
- 🚀 Быстрая обработка изображений
- 📊 Удобный формат вывода данных
